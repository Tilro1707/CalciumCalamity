# Calcium Calamity

Summon skeletons around a graveyard church and defend it from waves of enemies. Build graves to earn souls, spend them on Sword, Ax and Ranger skeletons, and give your skeletons elemental mutations (Fire, Ice, Lightning, Earth). If the church falls, the game is over.

Made for [Mini Jame Gam #55](https://itch.io/jam/mini-jame-gam-55).

## Tech

- Unity 6000.3.8f1, URP 2D

Open the folder in Unity Hub with the matching editor version.
